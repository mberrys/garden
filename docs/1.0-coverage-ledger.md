## Commands that must stay green

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run test:e2e
```

Playwright uses the production server on port 3100 with `GARDEN_FORCE_MOCK_AI=1`.
GitHub Actions runs the same commands in `.github/workflows/ci.yml`.
