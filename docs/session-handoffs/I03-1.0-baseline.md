# I03 — 1.0 baseline, provenance, transactions, remaining surfaces

Stacks on I02 PR [#57](https://github.com/mberrys/garden/pull/57). Implements the
post-I02 1.0 slices from the Chat → Codex overlay: coverage ledger, frozen
fixtures, shared provenance, workspace transactions, media/mini, Bases
TanStack/calendar/filters, interchange harness, folder worktrees, flavors,
profession packets, and prompt-to-surface.

Does **not** rewrite I00–I02. Text live UI stays markdown-source (`.garden-markdown`)
with a Writer `EditorAdapter` for conformance. Sheets stay Garden-native
(see `docs/sheets-engine-spike.md`).

## Decisions

- `SCHEMA_VERSION` 2: versioned `GardenRef`, PDF evidence/citations, database
  filters, `media` and `mini` kinds. Frozen v1 `.gardenspace` fixtures migrate.
- One workspace transaction primitive (`previewPlan` / `applyPlan`) reused by
  packet planting, flavor changes, and prompt-to-surface proposals.
- TanStack Table/Virtual is UI infrastructure; Garden database JSON stays
  canonical. 5k-row filter/sort evidence lives in `src/lib/database/query.test.ts`.
- Office interchange is independent adapters + structured warnings, not a
  mega-parser and not Univer Pro.
- Prompt-to-surface emits a constrained `MiniDescriptor` and a reviewable plan.
  Discard applies nothing.
